## Evidence and decision

The exact-topic Indonesian paper consistently uses **statistik urutan** in its
title, abstract, section 2.4, definition, and joint-density discussion. It also
uses **sampel acak**, **peubah acak**, **fungsi kepadatan peluang**, **fungsi
kepadatan peluang gabungan**, and **fungsi distribusi**. These agree with the
current Penn State component except for the stale order-statistics glossary
row.

For this Penn State edition, `order statistic(s)` is therefore rendered as
**statistik urutan**. `Statistik terurut` is mathematically intelligible and
remains a documented legacy alias in the separately released Random edition;
it is not treated as a mathematical defect requiring that completed edition
to be reopened. The current Penn State landing page, course-card alt text, and
translation ledger already used **Statistik Urutan**, so no reader prose needed
retroactive replacement. Glossary row `O006-TERM-0030` was updated to match the
existing reader and exact-topic field evidence before Lesson 01 translation.

Model provenance remains exactly `OpenAI Codex gpt-5.6-sol, Ultra`. All source,
author, and human-contributor credits remain preserved.
