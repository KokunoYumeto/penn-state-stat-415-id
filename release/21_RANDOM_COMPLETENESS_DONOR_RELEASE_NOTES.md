# O006/C140 — donor kelengkapan Random (Bahasa Indonesia)

Status publikasi: **tulang punggung Penn State lengkap (14/14); donor Random lengkap (tepat satu halaman); kursus C140 belum lengkap sampai pendamping orisinal selesai**. Donor ini adalah halaman Kyle Siegrist, *Random*, “Sufficient, Complete, and Ancillary Statistics”; bukan pengganti atau fork kedua dari edisi lengkap *Random* 29 halaman.

`01_RANDOM_COMPLETENESS_DONOR_OFFLINE_READER.zip` (610,303 byte) adalah pembaca HTML luring mandiri. `11_RANDOM_COMPLETENESS_DONOR_SOURCE_BACKEND.zip` (741,277 byte) memuat sumber kanonis, otoritas, backend modular, receipt, dan skrip pemutaran ulang. `41_RANDOM_COMPLETENESS_DONOR_STATIC_QA_EVIDENCE.zip` (9,581 byte) memuat bukti QA statis deterministik.

Hak komponen tetap terpisah: saksi resmi *Random* menyebut CC BY 2.0 sementara `Credits.html` menautkan CC BY 1.0; MathJax 3.1.2 adalah Apache-2.0; lapisan orisinal repositori adalah CC BY-SA 4.0; spine Penn State tetap CC BY-NC 4.0 kecuali dinyatakan lain. Agregat tidak direlisensi secara seragam dan memakai label platform `other-open`.

Provenans terjemahan dan rekayasa edisi: OpenAI Codex gpt-5.6-sol, Ultra. Semua kredit penulis sumber dan kontributor manusia dipertahankan.
