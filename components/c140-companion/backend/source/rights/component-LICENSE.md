# Lisensi dan atribusi

Materi orisinal dalam `components/c140-companion/` dilisensikan berdasarkan
Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0):
https://creativecommons.org/licenses/by-sa/4.0/

Provenans produksi materi: `OpenAI Codex gpt-5.6-sol, Ultra`.

Komponen ini menghubungkan, tetapi tidak menyalin atau merelisensi ulang,
materi Penn State STAT 415 (CC BY-NC 4.0 kecuali dinyatakan lain) dan donor
*Random* Kyle Siegrist (saksi hak CC BY 2.0 pada laman utama dan tautan CC BY
1.0 pada `Credits.html`). Hak komponen tersebut tetap terpisah. Tidak ada
dukungan Penn State atau Kyle Siegrist yang tersirat.

Dataset CP01 *Concrete Compressive Strength* karya I-Cheng Yeh, UCI Machine
Learning Repository, DOI `10.24432/C5PK67`, tetap **CC BY 4.0**. Atribusi yang
dipertahankan adalah: Yeh, I. (1998). *Concrete Compressive Strength*
[Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C5PK67. Byte mentah, anggota arsip, dan turunan data
yang setia tidak dilisensikan ulang sebagai CC BY-SA.
Berkas README asli juga meminta agar pemberitahuan hak cipta I-Cheng Yeh dan
rujukan berikut dipertahankan: Yeh, I.-C. (1998), “Modeling of strength of
high-performance concrete using artificial neural networks,” *Cement and
Concrete Research*, 28(12), 1797–1808,
https://doi.org/10.1016/S0008-8846(98)00165-3.

Dataset CP02 Dryad *Supporting data for assessing impacts of satellite GPS
transmitters on survival, nesting propensity, and nest success of greater
sage-grouse*, DOI `10.5061/dryad.573n5tbf3`, versi 3 / ID versi `268230`,
tetap **CC0 1.0**. Byte mentah dan turunannya tidak dilisensikan ulang sebagai
CC BY-SA. Bukti hak dan identitas byte kedua dataset berada di
`data/capstones/CP01/DATASET_PROVENANCE.json` serta
`data/capstones/CP02/{DATASET_PROVENANCE.json,RIGHTS_EVIDENCE.md}`.

Saksi halaman, API, legal-code, dan tajuk HTTP yang disimpan verbatim hanya
berfungsi sebagai bukti publik. Saksi itu diberi status `NOASSERTION`, tidak
dilisensikan ulang sebagai materi pendamping, dan tetap tunduk pada hak atau
ketentuan sumbernya masing-masing. Turunan redistribusi yang disunting demi
keamanan selalu memakai nama dan rekam perubahan terpisah.
