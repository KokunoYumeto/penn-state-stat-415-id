# Uji Neyman–Pearson teracak dengan *size* tepat

Ambil \(X\sim\operatorname{Binomial}(4,p)\) dan uji sederhana
\(H_0:p=0{,}25\) melawan \(H_1:p=0{,}60\) pada \(\alpha=0{,}10\). Rasio
likelihood naik terhadap \(x\), sehingga bentuk uji Neyman–Pearson adalah:
tolak bila \(X\ge3\), terima bila \(X\le1\), dan ketika \(X=2\) tolak dengan
peluang \(\gamma\). Randomisasi pada himpunan kesamaan merupakan bagian dari
teorema, bukan tambalan numerik; lihat [ref:O006-C140-CMP-D006].

<a id="O006-C140-CMP-SIM004-ALG001"></a>
## Menentukan peluang randomisasi

Pilih \(\gamma\) agar
\[
P_{0.25}(X\ge3)+\gamma P_{0.25}(X=2)=0{,}10.
\]
Perhitungan eksak memberi \(\gamma=0{,}2333333333\). Dengan nilai itu, size
eksak sama dengan 0,10 hingga galat aritmetika mesin. Power eksak pada
\(p=0{,}60\) adalah 0,55584.

<a id="O006-C140-CMP-SIM004-SIM001"></a>
## Pemeriksaan Monte Carlo

- Seed PCG64: `140004`.
- Replikasi untuk null dan alternatif: masing-masing 500.000.
- Size empiris: 0,099694.
- Power empiris pada \(p=0{,}60\): 0,555968.
- Kedua hasil harus berjarak kurang dari 0,002 dari probabilitas eksaknya.

Monte Carlo memeriksa implementasi, sedangkan size dan power analitis tetap
ditentukan oleh penjumlahan peluang binomial. Dengan demikian, fluktuasi acak
tidak boleh dipakai untuk mengubah \(\gamma\).
