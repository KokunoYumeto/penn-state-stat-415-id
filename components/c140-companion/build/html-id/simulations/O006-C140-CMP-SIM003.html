Endpoint Uniform: laju nonreguler dan kegagalan bootstrap biasa

Misalkan \(X_i\stackrel{\mathrm{iid}}{\sim}\operatorname{Uniform}(0,\theta)\) dengan \(\theta=1\), dan \(M_n=X_{(n)}\). Support bergantung pada parameter, jadi perangkat likelihood reguler tidak berlaku; lihat Likelihood nonreguler: empat mekanisme kegagalan. Distribusi eksak memberi \(P\{n(1-M_n)\le y\}=1-(1-y/n)^n\) untuk \(0\le y\le n\), yang menuju \(1-e^{-y}\). Karena itu gap endpoint memiliki laju \(n\), bukan \(\sqrt n\).

Rancangan yang dapat direproduksi

  • Seed PCG64: 140003.
  • Replikasi per ukuran sampel: 160.000.
  • Ukuran sampel: \(n\in\{10,30,100\}\).
  • Kuantil 95% empiris dibandingkan dengan nilai eksak \(n\{1-0{,}05^{1/n}\}\), bukan dengan satu ambang asimtotik untuk semua \(n\).

Rerata \(n(1-M_n)\) adalah 0,909071; 0,966904; dan 0,990172. Kuantil 95% empiris adalah 2,593076; 2,844298; dan 2,956510, masing-masing berjarak kurang dari 0,08 dari nilai eksaknya. Sementara itu, \(E\{\sqrt n(1-M_n)\}\) turun dari 0,287474 ke 0,099017: penskalaan akar-\(n\) justru runtuh menuju nol.

Mengapa bootstrap empiris biasa gagal

Sampel bootstrap berukuran \(n\) tidak memilih maksimum observasi asli dengan peluang \((1-1/n)^n\). Jadi maksimum bootstrap sama persis dengan \(M_n\) dengan peluang \(1-(1-1/n)^n\), yang menuju \(1-e^{-1}\approx0{,}6321\). Distribusi bootstrap bersyarat mempunyai atom besar di nol untuk gap \(M_n-M_n^*\), sedangkan limit target endpoint bersifat kontinu. Kode benar-benar membangkitkan sampel asal, menarik \(n\) indeks bootstrap, dan memeriksa apakah indeks maksimum asal terpilih. Simulasi menghasilkan massa 0,650250; 0,638775; dan 0,630850, sesuai peluang eksak masing-masing.
